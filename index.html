内容

  • すべてのアプリは, Baseを基に変更して作成しています.
  • いずれのアプリもSettings.htmlから起動します.
  • All applications are created by modifying the Base.
  • Each app is launched from Settings.html.

Base

  • 予備実験でいただいた意見を基に, 予備実験時のアプリを修正したものです.
  • This is a modified version of the app used in the preliminary experiment, based on the feedback received during that experiment.

RemoveButton

  • 回答確定ボタンを削除したものです.
  • I have removed the “Confirm Answer” button.

ResetParams

  • Calc.htmlからSettings.htmlに戻ったときに問題数と難易度の値ががリセットされるものです.
  • This causes the values ​​for the number of questions and the difficulty level to reset when returning from Calc.html to Settings.html.

WeakAppealOperator

  • ”/”演算子と”%”演算子についての注意を強調しないものです.
  • It does not emphasize the notes regarding the “/” and “%” operators.

WeakAppealText

  • 問題数と難易度の値についての注意を強調しないものです.
  • It does not emphasize the notes regarding the number of questions and the difficulty levels.
